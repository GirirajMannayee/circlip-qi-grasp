# Designed benchmark values (NOT measurements)

`Table16.csv` … `Table20.csv` are transcribed verbatim from the manuscript (Sec. 5.4).
They are **prospective design targets**: no robot trial has been run (Gate 4 is planned).
Do not cite them as results. They are replaced by trial-level data once the 360-trial study is complete
(see `stats/` and `data/trial_log_template.csv`).

Known manuscript inconsistency kept as printed (flagged in Sec. 5.4 of the paper):
Table 19 row A1 carries the C2 values (5.08 deg, 91.7 %) rather than the C1 values (6.72 deg, 86.7 %),
and A3 (2.76 deg) differs from C3 (3.21 deg).
